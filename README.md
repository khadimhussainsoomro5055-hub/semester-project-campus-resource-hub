# Campus Resource Hub

**A Centralized Platform for Sharing Academic Resources and Physical Books Across Campus**

## 1. Project Overview

Campus Resource Hub is a web-based platform designed to help university students share, find, and access academic resources in one centralized place.

Students can upload academic materials such as books, lecture notes, past papers, laboratory materials, presentations, and previous assignments. Other students can search, view, and download the required resources.

The platform also provides a physical book-sharing facility where students can list books they own and make them available for borrowing or exchange with other students.

To maintain the quality of the platform, uploaded academic resources will be reviewed and approved by an administrator before becoming available to other students.

## 2. Problem Statement

Students often face difficulties finding required academic resources because study materials are scattered across WhatsApp groups, personal messages, and other platforms.

This creates several problems:

- Difficulty finding previously shared study materials.
- Repeated requests for the same academic resources.
- Resources scattered across different groups and conversations.
- Difficulty locating materials according to course and semester.
- Difficulty finding students who own required physical books.
- Lack of a proper system for reviewing uploaded resources.

Campus Resource Hub aims to solve these problems by providing a centralized platform for academic resource sharing.

## 3. Project Objectives

- Develop a centralized platform for sharing academic resources.
- Allow students to upload, search, and download academic materials.
- Implement an administrator-controlled resource approval system.
- Provide resource filtering based on course, department, semester, and resource type.
- Introduce physical book-sharing and borrowing functionality.
- Allow students to report irrelevant, duplicate, or inappropriate resources.
- Improve access to academic materials across the university.

## 4. Project Scope

The project focuses on academic resource sharing within a single university community.

The system will provide:

- Student registration and authentication.
- Academic resource uploads.
- Resource approval and rejection.
- Resource searching and filtering.
- Viewing and downloading approved resources.
- Physical book listings.
- Physical book borrowing and exchange requests.
- Resource reporting.
- Administrator dashboard and platform management.

## 5. Main Project Modules

### 5.1 Student Registration and Login
Students can create accounts using their official university email addresses and log in to access the platform.

### 5.2 Password Reset
Students can submit password reset requests. The administrator verifies their identity before approving the reset process.

### 5.3 Student Dashboard
Provides a central interface where students can access academic resources, upload materials, search for books, manage uploads, and view their requests.

### 5.4 Academic Resource Upload
Students can upload:
- Academic books
- Lecture notes
- Past papers
- Laboratory manuals
- Presentations
- Previous assignments
- Other relevant study materials

### 5.5 Resource Approval
Uploaded resources remain pending until an administrator reviews and approves or rejects them.

### 5.6 Resource Search and Filtering
Students can search resources by keywords and filter them according to:
- Course
- Department
- Semester
- Resource type

### 5.7 Resource View and Download
Students can view the details of approved resources and download the corresponding files.

### 5.8 Physical Book Sharing
Students can list physical books they own, including their title, author, condition, and availability.

### 5.9 Physical Book Requests
Students can browse available physical books and send borrowing or exchange requests to book owners.

### 5.10 Resource Reporting
Students can report irrelevant, duplicate, incorrect, or inappropriate resources.

### 5.11 Admin Panel
Administrators can:
- Manage student accounts.
- Review uploaded resources.
- Approve or reject resources.
- Manage physical book listings.
- Review resource reports.
- Remove inappropriate or duplicate content.
- Manage resource categories.

## 6. User Roles

### Student
- Register and log in using university email.
- Manage personal profile.
- Upload academic resources.
- Search, view, and download approved materials.
- List physical books for sharing.

### Administrator

- Review and approve or reject uploaded resources.

## 8. File Storage

Uploaded files such as PDF and Word documents will be stored in a dedicated uploads directory on the server.

The database will store file information such as:

- File name
- File path
- File type
- Uploader
- Upload date
- Approval status

This approach keeps the database organized while allowing the system to manage uploaded academic resources.

## 9. System Workflows

### Academic Resource Workflow

1. Student logs in.
2. Student selects an academic resource.
3. Student uploads the file.
4. System validates the file.
5. File is stored on the server.
6. Resource information is stored in the database.
7. Resource status becomes Pending.
8. Administrator reviews the submission.
9. Administrator approves or rejects it.
10. Approved resources become available to students.

### Physical Book Workflow

1. Student lists a physical book.
2. Another student searches for the book.
3. Student sends a borrowing or exchange request.
4. Book owner accepts or rejects the request.
5. Students coordinate the physical exchange.
